# Evidências — Respostas

Esta pasta reúne evidências das **respostas produzidas pelo NotebookLM** durante a investigação.

## Objetivo

Documentar os resultados das interações com a IA e permitir relacioná-los aos prompts, às perguntas e às fontes que orientaram cada etapa.

## O que pode ser registrado

- capturas de tela das respostas;
- exportações ou registros autorizados das respostas;
- referências às respostas selecionadas para análise;
- observações sobre respostas que apresentaram convergências, diferenças ou necessidade de verificação.

## Respostas selecionadas no projeto

As duas respostas principais documentadas na pasta `respostas/` são:

- `resposta-01-pontos-convergencia.md` — síntese dos principais pontos de convergência entre as fontes;
- `resposta-02-diferencas-divergencias.md` — análise das diferenças de abordagem e possíveis divergências entre as fontes.

## Análise crítica

Uma resposta produzida pela IA não é, por si só, uma comprovação independente. As evidências devem ser analisadas em conjunto com as fontes utilizadas e com o prompt que originou a interação.

Quando necessário, deve ser registrada a diferença entre **informação diretamente fundamentada, síntese, inferência e afirmação que exige verificação adicional**.

## Critério de autenticidade

Devem ser adicionadas somente respostas realmente produzidas ou registradas durante o projeto. Não devem ser criadas respostas fictícias para preencher a pasta.
