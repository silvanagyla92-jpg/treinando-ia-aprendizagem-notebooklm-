# Prompts utilizados no projeto

Esta pasta reúne os prompts elaborados, testados e refinados durante a investigação sobre **Gestão Financeira Pessoal com NotebookLM**.

Os arquivos documentam diferentes etapas da interação com a IA, desde a exploração conceitual até a análise crítica e a síntese do conhecimento.

## Organização

- `prompt-01-exploracao-conceituacao.md` — exploração e conceituação.
- `prompt-02-aprofundamento.md` — aprofundamento de conceitos específicos.
- `prompt-03-comparacao-fontes.md` — comparação entre fontes e perspectivas.
- `prompt-04-analise-critica.md` — análise crítica das respostas e das evidências.
- `prompt-05-sintese.md` — integração e síntese dos conhecimentos.

## Objetivo

A documentação dos prompts permite acompanhar como as instruções foram construídas e refinadas, relacionando cada prompt às perguntas estratégicas, aos objetivos da investigação e aos resultados observados no NotebookLM.
