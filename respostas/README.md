Esta pasta reúne as respostas produzidas durante a investigação realizada no **NotebookLM**, organizadas para documentar os resultados obtidos a partir dos prompts e das fontes utilizadas no projeto.

## Estrutura

```text
respostas/
├── README.md
├── resposta-01-pontos-convergencia.md
└── resposta-02-diferencas-divergencias.md
```

Os arquivos individuais serão utilizados para registrar e analisar os resultados da investigação, preservando a relação entre as perguntas formuladas, as fontes consultadas e as respostas obtidas.
