# Fontes Internas

Seção destinada aos documentos estruturantes desenvolvidos especificamente para fundamentar e integrar o projeto.

## 1. Função das fontes internas

As fontes internas têm três funções principais:

1. organizar conceitos provenientes do conjunto de fontes externas;
2. integrar as dimensões financeira, matemática e comportamental da investigação;
3. fornecer uma base estruturada para análise, comparação e síntese.

Elas ajudam a transformar um conjunto heterogêneo de referências em uma estrutura de conhecimento coerente para o projeto.

## 3. Relação com as fontes externas

A lógica documental do projeto pode ser representada assim:

**Fontes externas → Curadoria → Integração interna → Prompts → Respostas → Avaliação crítica → Síntese**

Os documentos internos dependem conceitualmente do conjunto de referências externas. Por isso, uma afirmação apresentada nesses documentos deve, quando relevante, ser rastreável às fontes que fundamentaram sua construção.

## 4. Dimensões integradas

Os documentos internos permitem organizar a investigação em quatro dimensões principais:

| Dimensão | Papel |
|---|---|
| **Financeira** | organização de recursos, poupança, juros e planejamento; |
| **Matemática** | relações quantitativas utilizadas para representar fenômenos financeiros; |
| **Comportamental** | vieses, preferências temporais e fatores psicológicos; |
| **Educacional** | alfabetização financeira e capacidade de compreender decisões econômicas. |

Essa integração corresponde ao objetivo do projeto de estudar a Gestão Financeira Pessoal de maneira multidimensional.

## 5. Como interpretar os documentos

Os documentos internos devem ser diferenciados de fontes acadêmicas, institucionais e de divulgação.

- **Fonte externa:** material original produzido por uma instituição, pesquisador ou publicação.
- **Documento interno:** material elaborado para integrar e organizar informações do projeto.
- **Síntese:** combinação de informações provenientes de diferentes referências.
- **Inferência:** conclusão que não está necessariamente expressa de forma literal em uma fonte.

Essa distinção é essencial para evitar que uma síntese interna seja apresentada indevidamente como se fosse uma evidência primária.

## 6. Critérios de transparência

A documentação interna deve preservar:

- a distinção entre informação original e interpretação;
- a possibilidade de rastrear referências relevantes;
- a indicação de limites e incertezas;
- a separação entre evidência, síntese e inferência;
- a atualização das referências quando novas fontes forem incorporadas.

## 7. Relação com o NotebookLM

Os documentos internos fazem parte da arquitetura documental do projeto e podem atuar como fontes de integração dentro do processo de aprendizagem. O NotebookLM, entretanto, não deve ser considerado a autoridade final sobre a validade das afirmações.

A análise crítica continua necessária para verificar se uma resposta da IA está efetivamente apoiada nas fontes fornecidas ou se apresenta uma interpretação adicional.
