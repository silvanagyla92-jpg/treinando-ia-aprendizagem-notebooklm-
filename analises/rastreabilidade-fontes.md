A matriz serve para tornar explícita a origem das categorias utilizadas nos quatro documentos analíticos:

- [`convergencia-fontes.md`](./convergencia-fontes.md) — utiliza as referências para identificar compatibilidades temáticas.
- [`divergencias-fontes.md`](./divergencias-fontes.md) — utiliza as referências para diferenciar foco, método, finalidade e escopo.
- [`verificacao-afirmacoes.md`](./verificacao-afirmacoes.md) — estabelece o procedimento para conferir afirmações contra as fontes.
- [`sintese-final.md`](./sintese-final.md) — integra os achados e aponta para esta matriz como índice das 25 referências.

## 6. Critérios de rastreabilidade

Uma citação documental não significa que a fonte sustente qualquer afirmação sobre o tema. A correspondência deve ser avaliada pelo conteúdo específico da publicação.

Para cada afirmação relevante, o procedimento recomendado é:

1. identificar a afirmação;
2. identificar a fonte correspondente;
3. abrir a ficha documental;
4. consultar a publicação original quando necessário;
5. verificar contexto, método e escopo;
6. classificar a afirmação como fato, síntese, inferência, interpretação ou não confirmada.

As fontes internas são tratadas como documentos de integração e não como evidências independentes de terceiros.

## 7. Cobertura

A matriz foi criada para que nenhuma das 25 referências fique sem identificação dentro da camada analítica do projeto.
